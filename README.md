# Учебный интернет-магазин

## Тема контрольной работы №1

«HTML и CSS: разработка многостраничного сайта».

## Краткое описание проекта

Проект представляет собой учебный интернет-магазин, разработанный в рамках дисциплины «Фронтенд и бэкенд разработка».

На сайте реализована главная страница интернет-магазина с навигацией, информационными разделами, карточками товаров и формой оформления заявки.

Проект постепенно развивается в рамках практических работ. В дальнейшем он будет расширен до полноценного многостраничного сайта.

## Структура проекта

Проект имеет следующую структуру:

- `index.html` — главная страница сайта;
- `css/style.css` — основной CSS-файл со стилями сайта;
- `js/main.js` — JavaScript-код для работы кнопок, формы и модального окна;
- `images/` — папка для изображений проекта;
- `README.md` — описание проекта;
- `.gitignore` — список файлов и папок, которые не должны добавляться в Git.


## Используемые технологии

В проекте используются следующие технологии:

- HTML5 — для создания структуры страниц;
- CSS3 — для оформления сайта;
- JavaScript — для интерактивных элементов;
- Flexbox — для горизонтального расположения элементов;
- CSS Grid — для создания сетки карточек товаров;
- БЭМ — для организации названий CSS-классов;
- CSS-переменные — для хранения цветов, отступов и скруглений;
- Git — для контроля версий проекта;
- GitHub — для хранения репозитория;
- GitHub Pages — для публикации сайта.

## Описание обязательных страниц

В рамках контрольной работы №1 необходимо реализовать многостраничный сайт.

В итоговой версии проекта должны присутствовать следующие страницы.

### Главная страница

Главная страница содержит основную информацию о сайте.

На ней располагаются:

- шапка сайта;
- навигационное меню;
- главный информационный блок;
- популярные товары;
- преимущества проекта;
- контактная информация.

На текущем этапе эта страница реализована в файле `index.html`.

### Страница каталога

На странице каталога должен находиться список товаров интернет-магазина.

Для каждого товара планируется отображать:

- название;
- описание;
- цену;
- изображение;
- кнопку перехода к товару или оформления заказа.

### Страница карточки товара

Страница карточки товара должна содержать подробную информацию о выбранном товаре.

На ней планируется разместить:

- название товара;
- изображение;
- подробное описание;
- цену;
- кнопку заказа.

### Страница оформления заявки

Страница или раздел оформления заявки предназначен для ввода данных пользователя.

В проекте уже реализована форма заявки в модальном окне.

Форма содержит:

- имя;
- e-mail;
- телефон;
- дату связи;
- тему заявки;
- комментарий;
- согласие на обработку данных;
- кнопку отправки формы.

### Страница контактов

Страница контактов должна содержать информацию для связи с интернет-магазином.

На ней могут быть размещены:

- телефон;
- e-mail;
- адрес;
- социальные сети;
- другая контактная информация.

На текущем этапе базовая контактная информация располагается в подвале главной страницы.

## Самостоятельные доработки

В процессе выполнения проекта были самостоятельно добавлены и доработаны следующие элементы.

### Горизонтальное меню

Навигационное меню было изменено с вертикального расположения на горизонтальное.

Для этого используется Flexbox:

```css
.site-nav__list {
  display: flex;
  gap: var(--space-lg);
}
```

### Сетка карточек товаров

Карточки товаров размещены в виде сетки.

Для этого используется CSS Grid:

```css
.product-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: var(--space-md);
}
```

### Использование БЭМ

Для CSS-классов используется методология БЭМ.

Примеры классов шапки:

```text
site-header
site-header__inner
site-header__logo
```

Примеры классов навигации:

```text
site-nav
site-nav__list
site-nav__item
site-nav__link
site-nav__link--active
```

Примеры классов карточки товара:

```text
product-card
product-card__title
product-card__description
product-card__price
product-card__button
product-card--discount
```

Примеры классов формы:

```text
order-form
order-form__field
order-form__label
order-form__input
order-form__actions
```

БЭМ позволяет делать CSS-код более понятным, структурированным и удобным для дальнейшего развития проекта.

### CSS-переменные

В проекте используются CSS-переменные для хранения повторяющихся значений.

Например:

```css
:root {
  --color-primary: #0057b8;
  --color-text: #222222;
  --space-md: 16px;
  --radius-md: 8px;
}
```

Это позволяет изменять оформление сайта централизованно.

### Состояния элементов

Для интерактивных элементов добавлены состояния:

- `:hover`;
- `:active`;
- `:focus-visible`;
- `:disabled`.

Они позволяют показать пользователю реакцию интерфейса на действия.

### Модальное окно

Для оформления заявки используется элемент `dialog`.

При нажатии на кнопку «Заказать» открывается модальное окно с формой.

### Валидация формы

Для полей формы используется HTML-валидация.

Также ошибочные поля могут выделяться через:

```css
[aria-invalid="true"] {
  border-color: var(--color-danger);
}
```

### JavaScript

JavaScript используется для:

- открытия модального окна;
- закрытия модального окна;
- обработки кнопок «Заказать»;
- передачи выбранного товара в форму.

# LUMEN — интернет-магазин настольных ламп

## Тема контрольной работы №2

«Разработка и стилизация адаптивного многостраничного сайта интернет-магазина».

## Краткое описание проекта
LUMEN — учебный интернет-магазин настольных ламп для работы, учёбы и чтения.

На сайте представлены три модели: Lumen Base, Lumen Flex и Lumen Pro. Пользователь может просматривать каталог, фильтровать товары по назначению и цене, сравнивать характеристики, открывать подробную страницу товара и заполнять форму заявки.

Для проекта разработана собственная визуальная концепция: светлый фон, тёмно-зелёные акценты, лаконичные карточки и иллюстрации ламп, выполненные средствами CSS.

Проект является учебным. Товары, характеристики и отзывы вымышлены. Форма проверяет данные в браузере, но не отправляет их на сервер.

## Используемые технологии

- HTML5 — семантическая структура страниц.
- CSS3 — оформление и адаптивная вёрстка.
- JavaScript — фильтрация каталога, заполнение страницы товара и работа формы.
- Flexbox — расположение элементов навигации и компонентов.
- CSS Grid — сетки товаров, отзывов и основные раскладки страниц.
- БЭМ — организация CSS-классов.
- CSS-переменные — хранение цветов и общих параметров оформления.
- Git и GitHub — контроль версий и хранение кода.
- GitHub Pages — публикация сайта.

## Используемый CSS-фреймворк

CSS-фреймворк не используется.

Оформление реализовано самостоятельно в файле `css/style.css`. Для построения интерфейса применяются Flexbox, CSS Grid, медиазапросы и CSS-переменные.

Внешние библиотеки для работы интерфейса не требуются.

## Структура проекта

- `index.html` — главная страница: первый экран, преимущества, популярные товары, сравнение моделей, отзывы и FAQ.
- `catalog.html` — каталог товаров с фильтрацией по назначению и цене.
- `product.html` — подробная страница выбранной модели.
- `contacts.html` — контактная информация и кнопка открытия формы обратной связи.
- `css/style.css` — общие стили, оформление компонентов и адаптивность.
- `js/main.js` — данные товаров, фильтрация, модальное окно, валидация формы и кнопка «Наверх».
- `sitemap.xml` — карта сайта.
- `README.md` — описание проекта.
- `.gitignore` — исключения для Git.

## Реализованные страницы

### Главная страница

Содержит:

- шапку и основную навигацию;
- главный экран с переходом в каталог;
- блок преимуществ;
- карточки популярных товаров;
- таблицу сравнения характеристик;
- блок отзывов;
- блок часто задаваемых вопросов;
- информационное примечание;
- подвал сайта.

### Каталог

Содержит:

- хлебные крошки;
- список товаров;
- фильтр по назначению;
- фильтр по диапазону цен;
- кнопку сброса фильтров;
- счётчик найденных товаров;
- сообщение об отсутствии подходящих товаров.

На широких экранах панель фильтров закрепляется при прокрутке с помощью `position: sticky`.

### Подробная страница товара

Содержит:

- название и артикул модели;
- иллюстрацию товара;
- подробное описание;
- цену и наличие;
- характеристики;
- условия доставки и гарантии;
- комплектацию;
- рекомендации по использованию и уходу;
- кнопку оформления заявки.

Модель определяется параметром `id` в адресе страницы:

- `product.html?id=base` — Lumen Base;
- `product.html?id=flex` — Lumen Flex;
- `product.html?id=pro` — Lumen Pro.

При неизвестном идентификаторе отображается сообщение «Товар не найден».

### Контакты

Содержит демонстрационные контактные данные и кнопку открытия формы консультации.

## Список реализованных компонентов

1. **Шапка сайта** — логотип и закреплённая навигация.
2. **Главный экран** — заголовок, описание, иллюстрация и кнопки перехода.
3. **Хлебные крошки** — навигация по структуре сайта.
4. **Карточка товара** — иллюстрация, категория, название, описание, параметры, цена и кнопки.
5. **Подробная карточка товара** — отдельная страница с расширенной информацией.
6. **Фильтры каталога** — выбор назначения и диапазона цен.
7. **Таблица сравнения** — сопоставление характеристик трёх моделей.
8. **Блок отзывов** — оценка, заголовок, текст, автор, модель и дата.
9. **FAQ** — раскрывающиеся вопросы и ответы на основе `details` и `summary`.
10. **Модальное окно** — общая форма заявки на основе элемента `dialog`.
11. **Валидация формы** — проверка обязательных полей, имени, электронной почты, телефона и даты.
12. **Сообщение о результате** — уведомление об успешной проверке формы.
13. **Кнопка «Наверх»** — появляется после прокрутки страницы.
14. **Подвал сайта** — название проекта и дополнительные ссылки.

## Адаптивность и доступность

- Интерфейс адаптируется к компьютерам, планшетам и телефонам.
- Сетки перестраиваются с помощью медиазапросов.
- Таблица сравнения поддерживает горизонтальную прокрутку.

- Предусмотрена ссылка быстрого перехода к основному содержимому.
- Учитывается настройка уменьшения анимаций.

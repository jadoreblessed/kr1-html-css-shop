# LUMEN — интернет-магазин настольных ламп

React-версия магазина из КР1. В каталоге девять моделей с фильтрацией по назначению и цене. Сохранены отдельные адреса страниц, включая `product.html?id=flex`, и форма заявки в модальном окне. Заявку также можно открыть отдельной страницей. Форма проверяет данные в браузере и показывает результат проверки.

Автор — Зырянов Владислав Александрович, ЭФБО-10-25.

## Запуск

Нужен Node.js 20.19+ из ветки 20.x или 22.12+.

```bash
npm ci
npm run dev
```

Для проверки сборки выполните `npm run build`, затем `npm run preview`. Готовые файлы для статического хостинга находятся в `dist/`.

## Практика №12 — React и адаптивная вёрстка

- Пять страниц — главная, каталог, карточка модели, заявка и контакты. Повторяющиеся элементы вынесены в React-компоненты.
- Базовые стили находятся в `css/style.css`, медиазапросы Mobile First — в `css/responsive.css`. Сетка товаров перестраивается с одной до трёх колонок, а панель фильтров на широком экране переходит в боковую колонку.
- Главный экран использует отдельное кадрирование для мобильного экрана. Для фотографий товаров браузер выбирает размер через `picture`, `srcset` и `sizes`. Файлы находятся в `public/images/`.
- Поля заявки имеют высоту от 44 CSS px, на узком экране стоят в одну колонку. Таблица сравнения прокручивается внутри своего блока. Таблица характеристик на странице модели переносит текст внутри ячеек.

## Практика №13 — изображения и доступность

Для каждой фотографии товара указан `alt`, описывающий цвет и форму лампы. У главной иллюстрации есть описание сцены. Декоративные символы скрыты от скринридера. ARIA используется для различения областей навигации, названия диалога и блока прокрутки, подсказки к номеру телефона и текущей страницы. Изменения количества товаров и результат формы объявляет `role="status"`.

## Практика №14 — проверка адаптивности

Проверены все пять страниц в Chromium на ширинах **320, 360, 430, 768, 1024 и 1440 px**. На уровне страницы горизонтальной прокрутки нет.

- Сетка каталога и главной меняется с 1 на 2 и 3 колонки. Мобильное меню проверено отдельно.
- На 360 и 430 px Chromium выбирает `hero-mobile-480.webp`, на 768 px — `hero-mobile-800.webp`, на 1024 и 1440 px — `hero-1440.webp`. Карточки используют отдельные WebP-кандидаты и JPEG как резервный формат.
- Поля формы не выходят за экран. С клавиатуры проверены открытие формы, закрытие по Escape и возврат фокуса на кнопку. Также проверены невалидный телефон и успешное заполнение.
- Таблица сравнения прокручивается внутри блока, в том числе клавишей со стрелкой. Таблица карточки сохраняет две колонки с переносом длинных значений.

## Практика №15 — JavaScript для данных товара

`src/product-demo.js` берёт модель Lumen Flex и добавляет для примера прежнюю цену 1800 ₽ и логическое значение наличия. В объекте используются строки, числа и логическое значение. Прежняя цена используется в примере для консоли.

| Функция в `src/product-utils.js` | Результат для примера |
| --- | --- |
| `formatPrice(price)` | 1 500 ₽ |
| `calculateDiscount(product)` | 17% |
| `getProductStatus(product)` | В наличии |
| `describeProduct(product)` | Lumen Flex · Для работы и учёбы · 1 500 ₽ · В наличии |

Для расчёта скидки функция сравнивает цены, объединяет условия логическим оператором и выполняет арифметику с округлением. Чтобы увидеть все четыре результата, откройте страницу магазина и вкладку **Console** в DevTools. Сообщение называется «Практика №15 — Lumen Flex».
